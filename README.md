# Filmy City V4

Full-stack starter using Node.js, Express and SQLite.

## Run
1. Install Node.js 18+.
2. Run `npm install`.
3. Set environment variables `ADMIN_PASSWORD` and `SESSION_SECRET`.
4. Run `npm start`.
5. Open `http://localhost:3000`.

The app creates `filmycity.db` automatically. Movie management is protected by a server-side session. Use only movies, posters, trailers and video streams you are authorized to publish.
